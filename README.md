# Trabalho M2 — Banco de Dados

Trabalho da disciplina de Banco de Dados envolvendo:

- criação da estrutura do banco de dados;
- inserção de dados;
- junções;
- agregações;
- índices;
- uso do EXPLAIN;
- criação de usuário e permissões com DCL.

## Estrutura do projeto

- `schema.sql` — criação do banco e das tabelas
- `inserts.sql` — massa de dados
- `consultas.sql` — consultas A até J
- `indices.sql` — índices e EXPLAIN
- `permissoes.sql` — criação do usuário e permissões
- `prints/` — prints dos EXPLAIN
